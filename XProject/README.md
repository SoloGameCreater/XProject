# 三合一合成游戏 (Triple Merge Game)

## 项目概述

这是一个基于Unity引擎开发的三合一合成类休闲游戏，玩家通过将相同类型的物品合并在一起，形成更高级的物品，解锁新的游戏内容和区域。游戏机制类似于市场上流行的"合并游戏"（Merge Games）如"合并花园"、"合并农场"等。

## 游戏特点

### 核心玩法
- **三合一合成系统**：将三个相同类型的物品合并，升级为更高级物品
- **地图探索**：解锁和净化新区域，扩展游戏地图
- **资源收集**：通过宝箱和其他游戏机制获取资源

### 物品类型
- **宝箱 (TreasureChest)**：提供游戏资源和奖励
- **一般合成物 (MergeableNormal)**：可合成升级的基本物品
- **万能卡 (UniversalCard)**：特殊道具，可替代任意合成物品

### 地图系统
- **合成地块 (MergeableCell)**：游戏的基本地图单元，有多种状态
  - 可合成：可放置和合成物品的地块
  - 未净化：需要特定条件解锁的地块
  - 未解锁：尚未开放的地块
- **区域 (MergeableRegion)**：由多个地块组成的游戏区域

## 技术架构

### 框架与工具
- **UnityGameFramework**：基础游戏框架
- **YooAsset**：资源管理系统
- **UniTask**：异步编程支持
- **DOTween**：动画系统
- **TextMeshPro**：高质量文本渲染

### 设计模式
- **有限状态机 (FSM)**：管理游戏状态和流程
- **组件化设计**：使用组件模式构建游戏功能
- **对象池**：优化频繁创建和销毁的对象
- **单例模式**：管理全局系统和服务

### 性能优化
- **对象池化**：减少垃圾回收压力
- **资源管理**：优化资源加载和卸载
- **批处理**：减少绘制调用
