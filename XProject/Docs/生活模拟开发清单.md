# 生活模拟开发清单（可迭代版）

## 1. 使用说明
- 本清单用于逐步细化需求，达到“可执行阈值”后由 Codex 按清单实施。
- 状态字段统一使用：`未开始` / `进行中` / `已完成` / `阻塞`。
- 每次变更请在文末“变更记录”追加一行，保证可追溯。

## 2. 项目目标与范围（当前版）
- 目标：基于现有框架，落地一个生活模拟玩法最小可玩版本，并可扩展到可上线版本。
- 当前需求：
  - 1 个主角 + 2 个 NPC
  - NPC 可点击交互，支持弹窗/选项/对话
  - 主角与 NPC 互动动画，10 个序列帧动画
  - 动画支持快慢控制与状态切换
  - 抽象大地图，点击建筑按钮切换对应场景
  - 背包/图鉴系统
  - 存档功能

## 5. 风险与回滚位点
- 风险1：动画资源交付延迟  
  - 缓解：先用占位动画和统一时长  
  - 回滚：关闭互动动画，仅保留静态交互
- 风险2：切场景时状态丢失  
  - 缓解：先做关键状态快照，再切场景  
  - 回滚：改为单场景分区切换
- 风险3：存档字段频繁变动  
  - 缓解：提前引入版本号与默认值填充  
  - 回滚：临时锁定旧字段，仅增不改
