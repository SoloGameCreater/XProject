# 三合玩法系统架构文档

## 系统概述

三合玩法（Triple Merge）是一种基于合成机制的游戏玩法，玩家通过将三个相同的物品合成为更高级的物品，从而推进游戏进程。该系统主要由以下几个核心部分组成。

## 核心组件

### 1. 系统架构

```
TripleMergeSystem
├── Model - 数据模型
├── Gameplay - 游戏玩法控制
│   ├── MapManager - 地图管理
│   ├── CameraInputManager - 相机输入管理
│   └── TreasureManager - 宝箱管理
└── FSM - 状态机
```

## 主要功能模块

### 1. 相机控制系统

`TripleMergeCameraComponent` 负责处理相机的移动、缩放和输入控制，支持PC和移动设备的不同输入方式。

主要功能：
- 相机平移
- 相机缩放
- 边界限制
- 跟随拖拽物品

### 2. 地图管理系统

`TripleMergeMapManager` 负责管理游戏地图和地块，包括：
- 地图初始化
- 区域加载
- 寻找最近的空地块
- 选择地块物品

### 3. 合成系统

`MergeableCell` 是合成系统的核心，负责处理物品的放置和合成逻辑：

合成流程：
1. 检测连续相同物品
2. 执行合成动画
3. 计算合成结果
4. 生成新物品
5. 放置合成后的物品
6. 处理连锁合成

### 4. 物品系统

物品系统包含两个主要类：
- `ItemBase`: 所有物品的基类，处理基本的交互
- `OnCellObject`: 可放置在地块上的物品
- `MergeableObject`: 可合成的物品，支持拖拽、合成提示等功能

### 5. 宝箱系统

`TripleMergeTreasureComponent` 负责宝箱的生成和管理：
- 消耗宝箱资源
- 在地图上生成宝箱
- 宝箱飞行动画

## 交互流程

1. **物品拖拽**：
   - 玩家点击并拖拽物品
   - 系统检测拖拽状态并更新物品位置
   - 显示合成提示（如果可合成）

2. **物品放置**：
   - 玩家释放物品到目标地块
   - 系统检查目标地块状态
   - 执行放置或合成逻辑

3. **物品合成**：
   - 系统检测连续相同物品
   - 执行合成动画
   - 生成新物品并放置
   - 检查连锁合成

4. **相机控制**：
   - 玩家通过拖拽或滚轮控制相机
   - 系统根据输入设备类型处理不同的输入方式
   - 限制相机移动范围

## 存储系统

游戏状态通过 `SaveFileTripleMergeCellData` 进行持久化存储：
- 地块状态
- 放置的物品
- 净化值

## 优化策略

1. **对象池**：使用 `OnCellObjectPool` 管理物品对象，减少实例化和销毁开销
2. **资源管理**：使用 `ListPool`、`HashSetPool` 等临时集合池减少GC压力
3. **异步加载**：地图和资源的异步加载
4. **边界检查**：相机移动和缩放的边界限制

## 扩展性设计

系统通过组件化设计提供良好的扩展性：
- `ITripleMergeComponent` 接口定义了组件的生命周期
- `TripleMergeComponent` 抽象类提供了基础实现
- 各功能模块通过实现该接口进行扩展

## 待完成功能

### 1. 地块解锁功能 (@MergeableCell.cs)

地块解锁功能将允许玩家通过特定条件解锁被锁定的地块，扩展可用游戏区域。

#### 实现要点：
- **净化值配置**：
  - 为每个地块配置所需的净化值
  - 在编辑器中可视化配置净化值要求
  - 支持不同地块设置不同的净化值要求

- **净化值增加条件**：
  - 合成高级物品时增加净化值
  - 使用特殊道具直接增加净化值
  - 完成特定任务获得净化值奖励
  - 净化值变化时触发相应的视觉反馈

- **解锁流程**：
  - 当累计净化值达到要求时自动解锁地块
  - 解锁时播放特效动画
  - 更新地块状态并保存到存档

### 2. 区域解锁功能 (@MergeableRegion.cs)

区域解锁功能将允许玩家解锁整个区域，提供更大的游戏空间和新的游戏内容。

#### 实现要点：
- **区域解锁条件**：
  - 基于已解锁地块数量的解锁条件
  - 基于特定任务完成的解锁条件
  - 基于游戏进度的解锁条件

- **区域状态管理**：
  - 区域锁定/解锁状态的存储与读取
  - 区域解锁进度的可视化展示
  - 区域间的依赖关系管理

- **解锁奖励**：
  - 解锁新区域时提供特殊奖励
  - 新区域特有的游戏内容和玩法
  - 解锁成就系统的整合

- **UI交互**：
  - 区域解锁进度展示界面
  - 区域预览功能
  - 解锁提示和引导

## 总结

三合玩法系统是一个结构完善的游戏系统，通过组件化设计和清晰的职责划分，实现了高度可扩展和可维护的架构。系统支持多平台输入，并通过对象池等优化策略保证了良好的性能表现。待完成的地块和区域解锁功能将进一步丰富游戏内容，提升玩家体验。
